LectureBuilder v7.0 테스트 노트
================================
1. 프로젝트 목록 페이지 정상 표시 (로그인 후)
2. "강의 제작 스튜디오" 제목 + "새 프로젝트" 버튼 정상
3. 빈 상태 UI 정상 ("아직 프로젝트가 없습니다")
4. DB 마이그레이션 완료 (passwordHash, googleId 컬럼 추가)
5. 새 프로젝트 생성 → 5단계 위저드 테스트 필요

--- Step 테스트 결과 ---
Step 1: 아바타 선택 ✅ - 아바타 추가 다이얼로그 정상, 얼굴/역할/음성 선택 가능
Step 2: 스크립트 준비 ✅ - 3가지 모드(AI생성/분류/직접입력) 표시, 섹션 추가 가능
Step 3~5: 추가 테스트 필요

버그: "다음" 버튼이 하단 고정 바에서 클릭 이벤트 전파 문제 있음 - JS click으로는 정상 작동

--- 전체 5단계 테스트 결과 ---
Step 1: 아바타 선택 ✅ - 아바타 추가, 얼굴 갤러리, 역할/음성 선택
Step 2: 스크립트 준비 ✅ - 3가지 모드(AI생성/분류/직접입력), 섹션 추가, 저장
Step 3: 슬라이드 업로드 ✅ - 파일 드래그&드롭 영역, PPT/PDF/이미지 지원
Step 4: 매칭 에디터 ✅ - 슬라이드-스크립트 매칭, 미배정 스크립트 목록
Step 5: 미리보기 ✅ - 프로젝트 요약, 아바타 위치/크기/모양/투명도 설정, 최종 영상 생성

모든 5단계가 정상 렌더링되고 스텝 전환도 작동함.
UI 개선 필요사항:
1. Step 4 매칭 에디터 - 드래그&드롭 인터랙션 개선 필요
2. Step 4 펜 애니메이션 설정 UI 추가 필요
3. Step 5 미리보기 - 실제 슬라이드 프리뷰 표시 필요
4. 전체적인 디자인 폴리싱 필요
