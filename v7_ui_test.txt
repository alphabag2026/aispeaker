v7 LectureBuilder UI 테스트 결과
==================================
날짜: 2026-04-21

1. 프로젝트 목록 페이지 ✅
   - 네비바에 "강의 제작" 링크 정상 표시 (로그인 사용자)
   - 프로젝트 카드 표시: 제목, 설명, 상태 배지, 진행률 바
   - 새 프로젝트 생성 다이얼로그 정상

2. 5단계 위저드 ✅
   - Step 1 아바타 선택: 얼굴 갤러리, 역할, 음성 선택 정상
   - Step 2 스크립트: 3가지 모드(AI생성/분류/직접입력) 전환 정상
   - Step 3 슬라이드: 파일 업로드 영역 정상
   - Step 4 매칭 에디터: 슬라이드 썸네일, 스크립트 배치, 펜 도구 정상
   - Step 5 미리보기: 프로젝트 요약, 아바타 위치/크기/모양/투명도 설정 정상

3. 스텝 진행 바 ✅
   - 5단계 모두 표시, 완료된 스텝 클릭으로 돌아가기 가능
   - 이전/다음 버튼 정상 작동

4. 확인된 사항
   - 현재 Step 5에서 "슬라이드가 없습니다" 표시 (슬라이드 미업로드 상태)
   - 프로젝트 요약: 아바타 1명, 슬라이드 0장, 배정 스크립트 0/0
   - 아바타 위치/크기/모양/투명도 설정 UI 모두 정상
